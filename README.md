Built using a robust C++ core for memory manipulation (Dobby/KittyMemory) and a sleek Java overlay for the UI, communicating seamlessly via an internal socket server.

The menu features a sleek, dark-themed UI with categorized tabs and collapsible drop-down menus for easy navigation.

- **Never Wanted** (Clear Wanted Level)
- **Never Tired** (Infinite Stamina)
- **Freeze Mission Timer**
- **Max Armor**
- **Add Health** (Also repairs current vehicle)

### 🔫 Weapons
- Weapon Set 1, 2, 3, 4

### 📊 Statistics

- **Time:** Set Game Hour

### 📍 Teleportation

## 🚀 Installation

1. Ensure your device is **Rooted** (Magisk/KernelSU recommended).
2. Download the latest `ModMenu.apk` and install it.
3. Grant **Overlay Permission** and **Root Permission** to the app.
4. Open the app, tap **"Start"** to launch the floating icon.
5. Open **GTA: San Andreas**, tap the floating icon to open the menu, and press **"Start"** inside the menu to inject.
6. Once injected, the tabs will appear, and you can toggle your cheats.
